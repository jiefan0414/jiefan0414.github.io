# Personal Academic Website

This repository hosts my personal academic website.

## Website

The site is published through GitHub Pages at:

https://jiefan0414.github.io

## Repository Structure

- `index.html` — main webpage
- `stylesheet.css` — website styling
- `images/` — image assets
- `files/` — downloadable files such as CV or papers

## Update Instructions

After editing the website locally, run:

```bash
git add .
git commit -m "Update website"
git push
```
